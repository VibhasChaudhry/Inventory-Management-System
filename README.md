# Inventory-Management-System

Project Lifecycle Documentation
1. Project Title
Inventory Management System
2. Problem Identification
Many small shops and businesses manage inventory manually using registers or notebooks. This often leads to incorrect stock records, difficulty in tracking items, and errors during updates.

This problem is commonly seen in retail stores, warehouses, and small businesses.

Affected users:
• Shopkeepers
• Store managers
• Administrators
3. Need for the Solution
A digital inventory system is required to manage records efficiently and reduce manual work.

Benefits:
• Faster record management
• Organized storage of inventory details
• Reduced errors
• Easy searching and updating of products
• Better tracking of stock availability
4. Target Users
• Shopkeepers
• Store administrators
• Store managers
5. Proposed Solution
The proposed Inventory Management System will allow users to add, search, update, delete and display product records.

Users will interact through a menu-driven Python interface.

Data stored:
• Product ID
• Product Name
• Quantity
• Price
• Category
• Login details

The system helps users maintain organized records and track inventory efficiently.
6. Objectives of the Project
1. To create a digital inventory management system.
2. To add, search, update, delete and display records.
3. To reduce manual errors.
4. To organize data using MySQL.
5. To generate useful outputs and summaries.
